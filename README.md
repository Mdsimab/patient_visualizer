# Patient Visualizer

A modern healthcare data visualization platform built to simplify patient record analysis and improve medical data accessibility through interactive dashboards and visual insights.

---

## 🚀 Features

* 📊 Interactive patient data visualization
* 🩺 Patient record management
* 📈 Real-time analytics dashboard
* 🔍 Search and filter patient data
* 🔐 Secure authentication system
* 📱 Responsive UI for desktop and mobile
* ⚡ Fast and scalable architecture

---

## 🛠️ Tech Stack

### Frontend

* React.js
* Tailwind CSS
* Axios
* Chart.js / Recharts

### Backend

* Node.js
* Express.js
* MongoDB
* JWT Authentication

---

## 📂 Project Structure

```bash
patient_visualizer/
│
├── client/          # Frontend React application
├── server/          # Backend Express server

├── routes/          # API routes
├── controllers/     # Business logic

```

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Mdsimab/patient_visualizer.git
```

### Navigate to the project directory

```bash
cd patient_visualizer
```

### Install dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd ../server
npm install
```

---

## ▶️ Running the Application

### Start Backend Server

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the server directory and add:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
```
