# Patient Visualizer

Patient Visualizer is a frontend healthcare dashboard project focused on displaying patient-related data in a clean and interactive way. The project uses modern React tooling with reusable UI components, charts, and responsive layouts to create a smooth user experience.

## Features

* Interactive patient analytics dashboard
* Responsive UI design
* Charts and data visualization
* Reusable component-based architecture
* Fast development setup using Vite
* Type-safe development with TypeScript

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* shadcn/ui
* Recharts
* Chart.js
* React Router DOM
* React Query

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Mdsimab/patient_visualizer.git
```

Move into the project folder:

```bash
cd patient_visualizer
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
